02

가사와 프레이즈

사용 순서
  1. 한 줄에 한 가사 프레이즈 입력
  2. 각 줄의 시작 박과 길이 확인
  3. 음절별 박 위치와 MIDI 피치를 조정
  4. 파형을 재생하며 맞춘 뒤 MIDI 내보내기

가사만으로 실제 노래 음성이나 멜로디를 복원할 수는 없어요. 자동 가이드는 편집 가능한 초안입니다.

가사 없음시작 박·프레이즈 길이를 바꾸면 음절 배치가 다시 계산됩니다.
가사를 붙여 넣고 음절 가이드 만들기를 눌러 주세요.
04

가사로 AI 곡 생성

로컬 모델 상태 확인 중

가사와 장르 설명, BPM을 넣으면 이 PC의 ACE-Step 모델이 보컬 포함 곡을 생성합니다. 반복되는 가사 구절을 찾아 곡 구조 태그를 넣고, 결과 WAV를 다시 편집할 수 있습니다.

음성 참고는 가능한 음색·보컬 스타일 단서로만 사용됩니다. 특정 인물의 목소리를 그대로 복제하거나 동일하게 재현한다고 보장하지 않습니다. 목소리 표현은 분위기 설명 칸에 적어 주세요.

AI 생성 준비 중…

실제 진행률을 받을 수 있는 단계에서는 수치를 표시합니다. 모델 추론 중에는 완료 예상 시간이 일정하지 않아 진행 막대로 표시합니다.
처음 실행할 때 수 GB 모델을 준비합니다. 6GB VRAM 설정에서는 생성이 느려 CPU로 처리합니다. 원본 음원과 입력 가사는 이 PC 밖으로 전송하지 않습니다.
