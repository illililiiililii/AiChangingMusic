# AI Parody Music Studio

Windows 11에서 원곡과 새 가사, **사용 허락을 받은 말하기 음성**으로 패러디 노래를 만드는 로컬 데스크톱 앱입니다. AI 추론과 음성 학습은 사용자 PC에서 실행됩니다. 모델 설치와 오픈소스 다운로드에만 인터넷을 사용합니다.

## 주요 기능

- PySide6 GUI: 프로젝트 생성·저장·최근 목록, 오디오 재생·파형, 원곡 가사와 MIDI 음표 편집, 가사 편집·적합도, 음성 프로필, 단계별 재실행, 믹싱·출력, 모델 상태
- MP3/WAV/FLAC/OGG 입력 → Demucs 보컬/반주 분리 → faster-whisper 가사 초안 → librosa BPM·음정 분석
- Ollama의 **로컬** 모델로 개사 초안 생성 또는 수동 입력, 한글 음절·음표 길이 적합도 평가
- 한국어 TTS의 발음 정보를 음표 시각에 맞춘 보컬 합성(기본값), 기존 DiffSingerKR 선택 가능 → 허락받은 일반 말하기 음성으로 학습한 RVC 프로필 적용
- 보컬/반주 볼륨·고역 통과·가벼운 피크 압축·정규화, 최종 WAV/MP3 및 AI 생성 메타데이터 저장
- 각 단계의 파일과 JSON을 프로젝트 폴더에 보존하여 수정·재실행

## 설치와 실행

지원 환경은 Windows 11 x64, Python 3.10과 3.12, Git, NVIDIA 드라이버입니다. 개발 PC의 GTX 1660 SUPER 6GB에서 SVS·RVC, Demucs가 동작했습니다. CPU 실행은 Demucs와 Whisper에서 가능하며 전체 CPU 합성 속도는 검증하지 않았습니다. 설치에 모델·가상환경용 수 GB 여유 공간이 필요합니다.

1. [INSTALL.md](INSTALL.md)의 선행 프로그램을 설치합니다.
2. 저장소를 복제한 뒤 `install.bat`(또는 `setup.bat`)을 실행합니다. 두 가상환경, 오디오 도구와 로컬 모델을 설치합니다.
3. `run.bat`으로 GUI를 엽니다.
4. 처음 사용할 때 **모델·환경** 탭에서 설치 상태를 확인합니다.

## 사용 순서

1. **프로젝트 → 새 프로젝트**에서 저장 폴더를 고릅니다.
2. 원곡 파일을 선택하고 `원곡 가져오기 → 보컬·반주 분리 → 원곡 가사 인식 → 박자·멜로디 분석`을 실행합니다. 가사 인식 결과와 MIDI 음표를 검토·수정하고 **음표 저장**을 누릅니다.
3. **가사** 탭에 새 한글 가사를 쓰거나 주제와 스타일을 입력해 **로컬 AI 개사**를 실행합니다. 후자는 별도 [Ollama](https://ollama.com/download/windows) 설치, 서버 실행, `qwen3.5:4b` 모델 다운로드가 필요합니다. Ollama는 `127.0.0.1:11434`의 `/api/generate`만 사용합니다. 음절 수가 음표 수와 다르면 가사 또는 음표를 수정한 뒤 정렬하고, 결과를 확인합니다.
4. **목소리** 탭에서 명시적 학습·변환 허락을 확인합니다. 이미 가진 RVC `.pth`와 `.index`를 선택하거나 **10분 이상**의 일반 말하기 녹음 폴더를 골라 프로필을 학습합니다. 모델·학습 데이터는 Git에 포함되지 않습니다.
5. **생성·출력** 탭에서 **노래 합성 방식**을 고릅니다. 한국어 발음 우선 방식은 가사를 박자에 맞춘 말소리로 생성합니다. 정확한 음정으로 노래하는 기능은 기존 DiffSingerKR 방식이며, 발음은 덜 정확할 수 있습니다. `노래 합성 → 음색 변환 → 믹싱·출력`을 실행합니다. 발음 우선 방식을 사용할 때 목소리 탭의 **변환 보컬 음높이**는 먼저 `0`으로 설정하세요. 같은 버튼을 다시 누르면 그 단계만 재실행하며, 시작·끝 시간을 지정해 노래 구간만 재생성할 수도 있습니다. 입력이 준비되면 **전체 실행**으로 모든 단계를 순서대로 돌릴 수 있습니다. 프로젝트 폴더에 `final.wav`, `final.mp3`, `final.json`과 분리된 음원이 남습니다.

새 프로젝트는 한국어 발음 우선 방식으로 시작합니다. 이전 버전의 프로젝트는 기존 DiffSingerKR 설정으로 열리며, 생성·출력 탭에서 발음 우선 방식으로 바꾸면 변환 음높이가 `0`으로 맞춰집니다. 방식을 변경했거나 노래를 다시 합성했다면 음색 변환과 믹싱도 다시 실행해야 합니다.

발음 우선 합성은 TTS가 단어 앞에 넣는 무음을 최대 0.35초 당겨 단어의 실제 소리 시작을 음표 시각에 맞춥니다. 음표 정렬에 단어 중간의 긴 쉼이 있다면 해당 음절은 여전히 박자에서 벗어날 수 있으므로 **가사** 탭의 음절 시작·끝 시각을 확인하세요.

`python -m app`으로 직접 실행할 수도 있습니다. CLI 단계 실행은 `python -m app.core.cli <project.json> <stage>`를 사용합니다. 가능한 단계는 `import`, `separate`, `transcribe`, `analyze`, `generate`, `lyrics`, `train`, `sing`, `sing_segment`, `convert`, `mix`입니다.

## 현재 품질과 한계

짧은 원곡 데모에서 파일 가져오기, Demucs 분리, 한국어 ASR, BPM/음정 추정, 로컬 개사, SVS, RVC 변환, WAV/MP3 출력까지 실행했습니다. 가사 ASR은 노래에서 오인식이 발생했고 자동 음표 추출도 일부 음을 합쳐서 추정했습니다. 원곡 음절 시각은 Whisper 단어 시각의 균등 분할 추정이며 GUI에 표시됩니다. 가사·음표는 GUI에서 수정할 수 있습니다. DiffSingerKR 체크포인트는 **한글 음절 합성만** 지원하고, 영어 노래 합성은 현재 지원하지 않습니다. 음색 유사도와 한국어 발음 자연스러움은 자동 수치만으로 판정할 수 없어 청취 검토가 필요합니다. [APP_VALIDATION.md](APP_VALIDATION.md)에 실제 결과와 남은 검증 항목을 기록했습니다.

이 프로젝트의 DiffSingerKR 체크포인트는 CSD 데이터의 비상업 조건 때문에 비상업 기술 검증용입니다. 모델·입력 곡·화자에 대한 권리는 별도로 확인해야 합니다. 공개 배포본에는 모델 가중치, 사용자 음성, 학습 데이터, 출력 음악이 없습니다. [MODELS.md](MODELS.md), [DEPENDENCIES.md](DEPENDENCIES.md), [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 참고하세요.

문제 발생 시 GUI **생성·출력** 탭의 **로그 폴더 열기**를 누르거나 `logs/app.log`와 `logs/<프로필>-training.log`를 확인하고 [INSTALL.md](INSTALL.md)의 문제 해결 절을 따르세요.

음색 변환에 기계음이나 잡음이 심하면 목소리 탭의 **음색 반영 강도**를 낮춘 뒤 `음색 변환 → 믹싱·출력`을 다시 실행해 비교하세요. 학습 음원에 박수·음악·군중 소리·잔향이 많다면 깨끗한 단일 화자 녹음만 별도 폴더에 모아 새 프로필을 학습해야 합니다. 재학습은 기존 클립과 체크포인트를 재사용하지 않습니다.

변환 보컬이 화자의 평소 말하기 음역보다 높다면 목소리 탭에서 **변환 보컬 음높이**를 낮추세요. 남성 말하기 음성으로 높은 노래를 변환할 때는 `-12`부터 비교할 수 있습니다. **자음·숨소리 보호**는 값이 낮을수록 강하며, 발음이 뭉개지면 `0.20` 근처에서 비교하세요. 원곡 가사의 음절·음표 시각과 합성 보컬 자체도 함께 확인해야 합니다.

**직접 부른 보컬을 음색 변환**하려면 목소리 탭의 **음색 변환에 사용할 노래 보컬**에서 `직접 녹음한 보컬 파일`을 고르고 녹음 파일을 선택합니다. 반주를 들으면서 같은 시각에 맞춰 노래하되, 변환에 넣는 파일에는 반주가 섞이지 않게 녹음하세요. 녹음 파일의 시작점은 곡의 0초와 맞춰야 합니다. 직접 부른 음정을 유지하려면 **변환 보컬 음높이**를 `0`으로 설정하고 `음색 변환 → 믹싱·출력`을 실행합니다. 이 경로는 `singing.wav`를 거치지 않으며, 재학습도 필요하지 않습니다.

합성 보컬 경로에서는 짧은 음절 사이의 쉼을 모델에 전달하고 음절 시작 시각을 보존합니다. 다만 자동 추출된 음표나 수동 정렬의 음절 길이가 틀리면 합성 발음도 틀릴 수 있습니다. **가사** 탭에서 `음절 타이밍·음정 저장`으로 수정한 뒤 `노래 합성 → 음색 변환 → 믹싱·출력`을 다시 실행하세요.
