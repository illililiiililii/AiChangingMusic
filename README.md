# AI Parody Music Studio

Windows 11에서 원곡과 새 가사, **사용 허락을 받은 말하기 음성**으로 패러디 노래를 만드는 로컬 데스크톱 앱입니다. AI 추론과 음성 학습은 사용자 PC에서 실행됩니다. 모델 설치와 오픈소스 다운로드에만 인터넷을 사용합니다.

## 주요 기능

- PySide6 GUI: 프로젝트 생성·저장·최근 목록, 오디오 재생·파형, BPM 직접 지정, 피아노롤에서 음표 추가·삭제·이동·길이·음높이 편집, MIDI 가져오기·내보내기, 가사·음절 정렬 편집, 음성 프로필, 단계별 재실행, 믹싱·출력
- MP3/WAV/FLAC/OGG 입력 → Demucs 보컬/반주 분리 → faster-whisper 가사 초안 → librosa BPM·음정 분석; 선택 설치한 Basic Pitch로 별도 MIDI 초안 생성
- Ollama의 **로컬** 모델로 개사 초안 생성 또는 수동 입력, 한글 음절·음표 길이 적합도 평가
- 한국어 TTS의 발음 정보를 음표 시각에 맞춘 보컬 합성(기본값), 기존 DiffSingerKR 선택 가능 → 허락받은 일반 말하기 음성으로 학습한 RVC 프로필 적용
- 보컬/반주 볼륨·고역 통과·가벼운 피크 압축·정규화, 최종 WAV/MP3 및 AI 생성 메타데이터 저장
- 각 단계의 파일과 JSON을 프로젝트 폴더에 보존하여 수정·재실행

## 설치와 실행

지원 환경은 Windows 11 x64, Python 3.10과 3.12, Git, NVIDIA 드라이버입니다. 개발 PC의 GTX 1660 SUPER 6GB에서 SVS·RVC, Demucs가 동작했습니다. CPU 실행은 Demucs와 Whisper에서 가능하며 전체 CPU 합성 속도는 검증하지 않았습니다. 설치에 모델·가상환경용 수 GB 여유 공간이 필요합니다.

1. [INSTALL.md](INSTALL.md)의 선행 프로그램을 설치합니다.
2. 저장소를 복제한 뒤 `install.bat`(또는 `setup.bat`)을 실행합니다. 두 가상환경, 오디오 도구와 로컬 모델을 설치합니다.
3. `run.bat`으로 GUI를 엽니다.
4. 처음 사용할 때 **모델·환경** 탭에서 설치 상태를 확인합니다.

## 사용 순서

1. **프로젝트 → 새 프로젝트**에서 저장 폴더를 고릅니다.
2. 원곡 파일을 선택하고 `원곡 가져오기 → 보컬·반주 분리 → 원곡 가사 인식 → 박자·멜로디 분석`을 실행합니다. BPM이 틀리면 **직접 지정 BPM**에 실제 값을 입력하고 **첫 박 시각**과 **한 마디의 박 수**도 고칩니다. 이 값들은 피아노롤 눈금과 MIDI 내보내기에 쓰이며, 이미 분석된 음표의 초 단위 시각을 자동으로 늘이거나 줄이지 않습니다. **피아노롤에서 음표 편집**으로 음을 추가·삭제하거나 드래그해 시작 시각·음높이·길이를 고친 다음 저장합니다. 갖고 있는 `.mid` 파일도 가져올 수 있습니다.
3. **가사** 탭에 새 한글 가사를 쓰거나 주제와 스타일을 입력해 **로컬 AI 개사**를 실행합니다. 후자는 별도 [Ollama](https://ollama.com/download/windows) 설치, 서버 실행, `qwen3.5:4b` 모델 다운로드가 필요합니다. Ollama는 `127.0.0.1:11434`의 `/api/generate`만 사용합니다. 원곡과 같은 줄 수로 개사하면 정렬할 때 줄마다 음표 구간을 유지하며, 각 줄에서 늘거나 줄어든 음절은 그 구간 안에서 배분합니다. 정렬 결과의 음절 시각과 음표를 확인하세요.
4. **목소리** 탭에서 명시적 학습·변환 허락을 확인합니다. 이미 가진 RVC `.pth`와 `.index`를 선택하거나 **10분 이상**의 일반 말하기 녹음 폴더를 골라 프로필을 학습합니다. 모델·학습 데이터는 Git에 포함되지 않습니다.
5. **생성·출력** 탭에서 **노래 합성 방식**을 고릅니다. 한국어 발음 우선 방식은 단어의 합성 무음을 제거한 뒤 원곡 보컬의 가사 시각에 맞추고, 분리된 원곡 보컬의 음높이 궤적을 적용합니다. 무음 제거와 음높이 추적을 각각 끌 수 있습니다. 기존 DiffSingerKR 방식도 선택할 수 있습니다. 로컬 합성 가이드의 발음·박자는 사람의 녹음이나 잘 편집한 가창 보이스뱅크보다 떨어질 수 있습니다. `노래 합성 → 음색 변환 → 믹싱·출력`을 실행합니다. 프로젝트 폴더에 `final.wav`, `final.mp3`, `final.json`이 남습니다.

### 긴 노래의 RVC 음색 변환

로컬 합성 보컬은 입력 길이를 확인한 뒤 약 15초 구간으로 나눕니다. 직접 녹음·외부 보컬은 기본적으로 전체를 한 번에 RVC에 전달하며, **긴 녹음 자동 분할·경계 페이드 사용**을 선택하면 같은 구간 처리 방식을 사용합니다. 경계는 근처의 조용한 지점을 우선 선택하고 각 구간에 0.3초의 앞뒤 문맥을 더합니다. RVC 모델은 한 번만 로드해 구간을 순서대로 변환하며, 겹치는 영역을 서서히 섞어 원래 길이의 `converted.wav`로 병합합니다. 모든 구간이 있어야 새 출력 파일을 확정합니다. 기존 `convert → mix` 흐름과 프로젝트 파일명은 같습니다.

**생성·출력** 탭에 현재 구간, 완료/전체 구간 수, 백분율, 경과 시간, 예상 남은 시간, GPU와 현재 상태가 표시됩니다. 첫 구간이 끝나기 전 ETA는 `계산 중`입니다. 이후 ETA는 완료된 구간의 실제 처리 시간 평균으로 갱신됩니다. 준비·병합 시간이나 GPU 상태 변화에 따라 실제 남은 시간과 차이가 날 수 있습니다. **현재 작업 중단** 버튼은 RVC 하위 프로세스까지 종료합니다. 진행이 3분 이상 멈추거나 완료된 구간보다 현재 구간이 크게 오래 걸리면 경고만 표시하고 자동으로 끝내지 않습니다.

`logs/app.log`에는 작업·구간 시작/완료, 처리 시간, 종료 코드와 오류가 기록됩니다. `logs/rvc-날짜-식별자.log`에는 실행 명령·설정, 선택 GPU, RVC 표준 출력과 오류 출력이 실시간으로 기록됩니다. GUI의 **로그 폴더 열기**로 확인할 수 있습니다. GPU는 사용 가능한 장치 하나를 선택해 순차 변환하며 두 장을 동시에 사용하지 않습니다. GPU를 선택할 만큼 여유 VRAM이 없으면 CPU/자동 장치로 실행될 수 있으므로 표시된 GPU를 확인하세요. 추가 패키지는 필요하지 않습니다.

### 사용자가 직접 조정하는 멜로디와 가이드 보컬

- **Basic Pitch 초안:** **모델·환경 → Basic Pitch 선택 설치**는 Python 3.10 전용 환경에 설치합니다. **원곡 → Basic Pitch로 보컬→MIDI 초안**은 분리된 `vocals.wav`에서 음표 후보를 만들며, 현재 편집 중인 음표를 덮어쓰지 않습니다. **Basic Pitch 초안 검토**로 피아노롤에서 겹친 음을 정리하고 적용하세요. 음높이·박자·BPM은 반드시 귀로 확인해야 합니다. [Spotify Basic Pitch 공식 문서](https://github.com/spotify/basic-pitch#readme)
- **직접 노래 녹음:** **목소리 → 마이크 녹음 시작/중지**로 프로젝트 폴더에 WAV를 녹음하거나 **내가 직접 노래한 녹음**에서 보컬 파일을 선택하세요. 헤드폰으로 반주를 들으며 마이크에는 보컬만 들어가게 하세요. **직접 녹음·외부 보컬 시작 위치**에서 초 단위로 맞출 수 있습니다. `+`는 녹음을 늦게 시작하게 하고 `-`는 녹음 앞부분을 잘라 앞당깁니다. 기본으로 **녹음한 발음·박자·음높이 그대로 따라가기**가 켜져 RVC 피치 변경을 0으로 적용합니다. 이 설정을 끄면 **변환 보컬 음높이** 값을 적용합니다. 긴 녹음의 자동 분할·경계 페이드는 별도 선택 사항입니다. 그 뒤 **녹음 따라 음색 변환 → 믹싱·출력**을 실행하세요. 이 경로는 로컬 합성 `singing.wav`나 원곡 멜로디 추적을 사용하지 않습니다. 기존 프로젝트를 처음 열 때도 녹음 추종 옵션이 기본으로 적용되며, 저장해 둔 피치 변경값은 옵션을 끄면 다시 사용할 수 있습니다.
- **OpenUtau:** 피아노롤에서 **OpenUtau용 MIDI 내보내기**를 누른 뒤 [OpenUtau의 MIDI 가져오기](https://github.com/openutau/OpenUtau/wiki/Getting-Started)를 사용합니다. 한국어를 지원하는 가창 보이스뱅크·phonemizer를 직접 선택하고 보컬을 렌더한 후, 앱의 **목소리 → OpenUtau·외부 툴에서 만든 보컬**로 가져오세요. OpenUtau는 [DiffSinger를 지원](https://github.com/openutau/OpenUtau/wiki/DiffSinger-support)하지만 별도 설치와 호환 보이스뱅크가 필요합니다. MIDI 내보내기는 음표와 BPM을 전달하며, 가사는 OpenUtau에서 검토·입력해야 합니다.

새 프로젝트는 한국어 발음 우선 방식으로 시작합니다. 이전 버전의 프로젝트는 기존 DiffSingerKR 설정으로 열리며, 생성·출력 탭에서 발음 우선 방식으로 바꾸면 변환 음높이가 `0`으로 맞춰집니다. 방식을 변경했거나 노래를 다시 합성했다면 음색 변환과 믹싱도 다시 실행해야 합니다.

`python -m app`으로 직접 실행할 수도 있습니다. CLI 단계 실행은 `python -m app.core.cli <project.json> <stage>`를 사용합니다. 가능한 단계는 `import`, `separate`, `transcribe`, `analyze`, `install_basic_pitch`, `basic_pitch`, `generate`, `lyrics`, `train`, `sing`, `sing_segment`, `convert`, `mix`입니다.

## 현재 품질과 한계

짧은 원곡 데모에서 파일 가져오기, Demucs 분리, 한국어 ASR, BPM/음정 추정, 로컬 개사, SVS, RVC 변환, WAV/MP3 출력까지 실행했습니다. 가사 ASR은 노래에서 오인식이 발생했고 자동 음표 추출도 일부 음을 합쳐서 추정했습니다. 원곡 음절 시각은 Whisper 단어 시각의 균등 분할 추정이며 GUI에 표시됩니다. 가사·음표는 GUI에서 수정할 수 있습니다. DiffSingerKR 체크포인트는 **한글 음절 합성만** 지원하고, 영어 노래 합성은 현재 지원하지 않습니다. 음색 유사도와 한국어 발음 자연스러움은 자동 수치만으로 판정할 수 없어 청취 검토가 필요합니다. [APP_VALIDATION.md](APP_VALIDATION.md)에 실제 결과와 남은 검증 항목을 기록했습니다.

이 프로젝트의 DiffSingerKR 체크포인트는 CSD 데이터의 비상업 조건 때문에 비상업 기술 검증용입니다. 모델·입력 곡·화자에 대한 권리는 별도로 확인해야 합니다. 공개 배포본에는 모델 가중치, 사용자 음성, 학습 데이터, 출력 음악이 없습니다. [MODELS.md](MODELS.md), [DEPENDENCIES.md](DEPENDENCIES.md), [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 참고하세요.

문제 발생 시 GUI **생성·출력** 탭의 **로그 폴더 열기**를 누르거나 `logs/app.log`와 `logs/<프로필>-training.log`를 확인하고 [INSTALL.md](INSTALL.md)의 문제 해결 절을 따르세요.

음색 변환에 기계음이나 잡음이 심하면 목소리 탭의 **음색 반영 강도**를 낮춘 뒤 `음색 변환 → 믹싱·출력`을 다시 실행해 비교하세요. 학습 음원에 박수·음악·군중 소리·잔향이 많다면 깨끗한 단일 화자 녹음만 별도 폴더에 모아 새 프로필을 학습해야 합니다. 재학습은 기존 클립과 체크포인트를 재사용하지 않습니다.

변환 보컬이 화자의 평소 말하기 음역보다 높다면 목소리 탭에서 **변환 보컬 음높이**를 낮추세요. 남성 말하기 음성으로 높은 노래를 변환할 때는 `-12`부터 비교할 수 있습니다. **자음·숨소리 보호**는 값이 낮을수록 강하며, 발음이 뭉개지면 `0.20` 근처에서 비교하세요. 원곡 가사의 음절·음표 시각과 합성 보컬 자체도 함께 확인해야 합니다.

**직접 부른 보컬을 음색 변환**하려면 목소리 탭의 **음색 변환에 사용할 노래 보컬**에서 `내가 직접 노래한 녹음`을 고르고 녹음 파일을 선택합니다. 반주를 들으면서 같은 시각에 맞춰 노래하되, 변환에 넣는 파일에는 반주가 섞이지 않게 녹음하세요. 녹음 파일의 시작점을 **직접 녹음·외부 보컬 시작 위치**에서 조정하세요. 기본 **녹음한 발음·박자·음높이 그대로 따라가기** 옵션을 켜고 `녹음 따라 음색 변환 → 믹싱·출력`을 실행합니다. RVC 자체가 음색을 다시 합성하므로 발음의 완전한 복제는 보장되지 않으며, 결과에 잡음이 있으면 음색 반영 강도를 낮춰 다시 들어보세요. 이 경로는 `singing.wav`를 거치지 않으며, 재학습도 필요하지 않습니다.

합성 보컬 경로에서는 짧은 음절 사이의 쉼을 모델에 전달하고 음절 시작 시각을 보존합니다. 다만 자동 추출된 음표나 수동 정렬의 음절 길이가 틀리면 합성 발음도 틀릴 수 있습니다. **가사** 탭에서 `음절 타이밍·음정 저장`으로 수정한 뒤 `노래 합성 → 음색 변환 → 믹싱·출력`을 다시 실행하세요.
